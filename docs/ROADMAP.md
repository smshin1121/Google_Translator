# 개발 순서

이번 준비 이후 각 단계는 앞 단계의 실제 측정 결과를 반영합니다. 일정은 아직 확정하지 않았습니다.

| 단계 | 구현 | 산출물 / 통과 조건 |
| --- | --- | --- |
| 0. 준비 | 앱 골격·공통 정책·Watch 프로토콜·개발 문서·저장소 | 구조 검사, Mac 빌드 준비 |
| 1. 텍스트와 Watch | Mac 빌드 수정, Apple 언어팩 설치, 양방향 번역·공유, Watch 연결 | iPhone/Watch 실기기 기본 흐름과 비행기 모드 시험 |
| 2. Gemma 실험 | iOS 전용 LiteRT-LM 연결, 모델 내려받기/삭제/검증, CPU/GPU 비교 | 15 Pro의 속도·메모리·발열·배터리·번역 품질 표 |

## 바로 다음 Mac 작업

1. 이 저장소를 Mac mini에서 열고 Config/Local.xcconfig에 팀과 고유 번들 ID를 설정합니다.
2. bash scripts/check_mac.sh로 공통 Swift 테스트, iOS/Watch 빌드와 Watch 포함 위치를 검사합니다.
3. iPhone과 Watch에 개발 앱을 설치하고 한국어/영어 언어팩을 준비합니다.
4. 텍스트 양방향 번역, 비행기 모드, Watch 연결·응답·백그라운드 실패를 기록합니다.
5. 기본 흐름이 안정되면 Gemma 전용 어댑터와 모델 다운로드 관리를 시작합니다.

## 선택이 필요한 시점

- 단계 2: Gemma를 기본 번역 엔진으로 사용할지 Apple Translation을 기본으로 유지할지 측정 후 정합니다.
- 단계 3: 온라인 제공자·개인 API 호환 형식·예산을 정합니다. 현재는 비밀 키가 필요하지 않습니다.
- 단계 5: 원본 녹음 보관 정책과 내보내기 형식을 정합니다.
- 단계 6: 화자 분리의 추가 모델 비용과 정확도를 확인합니다.
- 단계 8: Watch 단독 온라인의 필요성을 실제 사용 흐름으로 확인합니다.
