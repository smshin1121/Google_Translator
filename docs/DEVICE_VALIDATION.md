## 모델과 음성 통합 후

- Gemma: 모델 버전/checksum, CPU/GPU, 최초/재시작 초기화 시간, 첫 토큰, 전체 번역 시간, peak memory, thermalState, 배터리 변화.
- 전사: 한국어/영어 지원 확인, 모델 설치, 조용한 환경/회의실/원거리/겹침 발화, WER와 한국어 CER.
- Apple 전사와 WhisperKit을 같은 오디오로 비교합니다. Moonshine 한국어는 스트리밍과 라이선스 조건을 확인한 뒤 후보 여부를 정합니다.
- 평가 자료 eval/ko-en-cases.json의 20문장에 대해 의미, 숫자/이름/부정, 요청 어조, 누락/추가를 사람이 검토합니다. 정확한 한 문자열과 일치하는지만으로 점수화하지 않습니다.
- 회의: 30분·60분, 전화 수신·잠금·이어폰 제거·저장 공간 부족·앱 재시작에서 확정 구간과 파일 복구.
- 화자 구분: 2명/3명/겹침 발화와 수정 흐름. 확신이 낮을 때 이름을 지어내지 않는지 확인합니다.
- 회의록: 원문 근거 연결, 담당자/기한 불명, 부정된 결정, 논의와 확정 구분.
- 온라인/API: HTTP 오류·인증 만료·속도 제한·연결 끊김·요청 취소·비용 표시, 오프라인 모드에서 외부 호출 차단.
- 라이브 API: 10분 초과 등 제공자 세션 제한과 재연결, 앞뒤 구간 중복/누락 검증.
- Watch: 요청 30초 지연, iPhone 앱 종료, 재연결, 오래된 응답, 중복 요청, 긴 문장/결과, 시스템 받아쓰기의 오프라인 여부를 별도 확인합니다.
