# 요구사항

기준일: 2026-10-11. 사용자 요청을 바탕으로 작성했습니다.

## 환경과 범위

- iPhone 15 Pro, 사용자 보고 iOS 26.6.2.
- Mac mini M1 1세대, 사용자 보고 Xcode 26.4.0. 실제 macOS 버전과 Xcode 기기 연결은 Mac에서 확인합니다.
- Apple Watch SE 3, 사용자 보고 watchOS 26.0 (23R350).
- 초기 언어 한국어↔영어. 이후 언어별 지원·모델·음성·품질을 검증하고 확장합니다.
- iOS와 watchOS 최소 배포 버전은 26.0으로 설정합니다.
- 준비 범위: 네이티브 앱 시작 코드, 구조, 개발 절차, 품질 기준, 지정한 GitHub 저장소 연결.
- 이번 준비 단계에서 App Store 배포, 유료 API 호출, 대규모 모델 다운로드는 수행하지 않습니다.

## 처리 모드

오프라인은 사용자의 텍스트·음성·회의 기록을 외부 서버에 전송하지 않습니다. 최초 언어팩/모델 다운로드는 별도 준비 동작이며 인터넷이 필요합니다. 로컬 엔진 실패 시 외부 API로 자동 전환하지 않습니다.

온라인은 앱 서비스 서버를 사용하는 모드입니다. 개인 API는 사용자가 지정한 서비스와 본인 키를 사용하는 모드입니다. 제공자와 가격은 실제 연결 단계에서 정합니다. 혼합 처리(로컬 전사 + 서버 번역)는 향후 별도 선택과 전송 범위 표시를 추가한 뒤 제공합니다.

## 품질 기준 초안

아래 수치는 측정 결과가 아닌 제품 목표이며, 초기 실기기 측정 후 조정합니다.

- 평가 문장의 숫자·금액·시간·부정 표현·이름·역할 보존을 우선합니다.
- 5~15초 발화의 마지막 확정 단어 이후 번역 자막 표시 p95 3초 이내를 초기 목표로 둡니다.
- 회의 기록은 전화·마이크 변경·잠금·저장 공간 부족 시 이미 확정된 구간을 유지해야 합니다.
- 모델·음성 처리·화자 분리의 메모리와 열 상태를 함께 측정합니다.
- 회의록의 결정과 할 일은 근거 구간을 표시하고 원문에 없는 담당자/기한을 만들지 않습니다.
- 실시간 통역은 발화 구간 단위로 개발하며, 완벽한 동시통역이나 겹침 발화의 정확한 분리를 전제로 하지 않습니다.
